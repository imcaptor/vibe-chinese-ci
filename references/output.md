# 输出规范

## 首次三稿

每稿只展示：

1. 风格品目及一句差异说明；
2. `词牌·题目`（无题目则只列词牌）；
3. 正文；
4. 简短状态：格律、词韵、查重，以及是否有人工确认项。

不要同时展开三份逐字报告。

## 选稿后的完整报告

- 规范词牌名、别名和《钦定词谱》正体索引；
- 总字数、分片、句读和逐句字数；
- 逐句平仄、韵位与《词林正韵》韵部；
- 领字、一字豆、叠句、对偶、叶韵和换韵；
- 多音、入声及古今音疑难；
- 查重命中句、作者、时代、作品名和相似程度；
- 最终状态。

最终状态只允许：

- `通过`
- `需人工确认`
- `本地校验／待接口复核`
- `不通过`

有未解释硬伤时只能使用“不通过”，不得用审美说明掩盖格律错误。
