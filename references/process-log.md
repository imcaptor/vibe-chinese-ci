# 词作项目档

每首词是可继续推进的项目，目录为 `archives/vibe-chinese-ci/projects/<词牌>-<题目>/`。项目档保存上下文与过程，不等同于定稿归档。

## 目录

```text
<词牌>-<题目>/
├── PROJECT.md    # 创作简报、决策、当前状态
├── VERSIONS.md   # 全文版本历史与校验结果
└── SOURCES.md    # 有外部材料时才建立
```

## PROJECT.md 必填字段

- 题目、词牌、正体、项目状态、作者／发起人
- 题旨／立意；素材、事实边界与情感落点
- 用户明确要求、审美方向、禁忌与已锁定的内容
- 章法方案、上下片关系、用韵／声律要求
- 当前采用稿、未决问题、下一步
- 决策日志：每条写时间、来源与取舍理由；未知材料明确标“未提供／待核”。

## VERSIONS.md 追加模板

```markdown
## vNN｜YYYY-MM-DD HH:mm｜来源：用户／助手

- 操作：新填／用户来稿／改字／改句／精修
- 改动：一句话说明；若只收到局部，写明未提供部分。
- 格律：通过／需人工确认／本地校验／待接口复核／不通过
- 查重：通过／需人工确认／不通过

【正文】
……
```

- 每个候选、用户来稿和失败稿均按发生次序追加，版本号只增不改。
- 展示前完成写入；用户后续修改也照录并同步更新 `PROJECT.md`。
- 题目未定时暂用 `未题`；题目确定后保留历史并在 `PROJECT.md` 记别名，不改写旧版本。
