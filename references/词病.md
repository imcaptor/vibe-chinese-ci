# 词病自检与处置

本清单用于古典词创作、精修与评读。先让词意、气脉与自然语言成立，再执行禁忌；为避小病而伤大意、真情或自然者不避。所有意象须有来处：无前后文支撑的突兀名词，按逻辑断裂处理。

## 工作顺序与分级

1. 每首候选先做格律校验；通过后再做本清单自检与查重。
2. 候选阶段优先剔除：明显凑韵、义理断裂、无意重字／重意、虚假对仗、时空或事实错误、跑题。
3. 定稿阶段将自检并入修改建议：能小改先小改；改动会伤词意而原句仍成立者标“可商榷”，说明保留理由或替代方案。
4. **硬伤**：通常必须修改，或明确提醒作者。**候选筛查**：创作时主动避开，成稿先衡量是否伤意。**人工点评**：给建议，不一票否决。**参考背景**：知识或风格提醒，不直接判错。

## 一、用韵与声律

- 无韵、出韵：**硬伤**。词须依当前正体的韵位、平仄韵及换韵要求用韵。
- 重韵：**候选筛查**；同一韵脚字无意重复应改。有意复沓须说明其声情功能。
- 凑韵：**硬伤／高优先修改**；韵脚使句意反常、虚浮或失实，须换韵脚或重造句。
- 句句押韵：**候选筛查**；非韵位押韵易破节奏，除特殊设计外避免。
- 平仄紊乱、孤平、三平调：**硬伤**；以 `analyze-ci.mjs` 的当前词谱逐字结果为准，候选不展示有硬伤者。
- 三仄调：**候选筛查**；若板滞、尾势发死则改。古音复杂的声病、险韵僻韵、拗句拗救边界及名家破格，暂不自动硬判，标人工确认。

## 二、对仗与字词

- 对仗在词中通常较宽；除词谱明定的对偶位外，不对仗不是硬伤。属对偏枯、不匀为**人工点评**。
- 同字不作硬病；无意重字、重意须优先避免，有意重复胜过无意避忌。
- **实字复沓：** 同篇中名词、动词等实字尽量不重复；若非回环、复沓等有明确声情作用，应优先换字或改句。虚字、结构字不以此苛求。
- 杜撰词汇、颠倒词汇、割舍词汇：**候选筛查**。为字数、平仄或押韵而造成费解、不似活汉语者改；可感可解的新词、合法古典倒装可留。
- 专用奇字、卖弄叠字：**人工点评**。僻字仅限题材、典故、关键物名之需；叠字须服务声音、景象或情绪。

## 三、句法与章法

- 句法雷同、语意重复（含合掌）、敷衍凑句：**候选筛查**。删掉不损境界的垫字、废话、套语。
- 相次丛聚、出语突兀、有句无篇：**人工点评**。同类物象不可密集堆砌；句子须有前因后承；有佳句而无全篇须重排章法。
- 杂凑成章、虎头蛇尾、血脉不贯：**人工点评**。结尾须有回响、照应或转深；气脉问题优先重构，不只换字。
- 时空错乱：**候选筛查**；季节、时辰、空间转换无交代应改，梦境、回忆、跳切须有信号。
- 自相矛盾：**硬伤**；事实、心理、动作前后冲突必须改。

## 四、修辞、立意与境界

- 比喻不当、用典冷僻／繁多、情景不谐、情意直露、虚情假意、景外设景、有理乏趣、粘滞物相：**人工点评**。让理从象中出，情落于具体景、动作、细节；典故不可替作者说话。
- 夸张失度、写景泛泛：前者**人工点评／候选筛查**，后者**候选筛查**。景须有地点、时令、动作或个性，夸张须有生活依据。
- 落入窠臼、翻新入魔、立意浅俗：**人工点评**。不以套路替代余味与承担，也不为求新反常识、弄巧成拙。
- 价值判断须合乎基本的人伦与公序，不宣扬仇恨、暴力或歧视。

## 五、题目、事实与蹈袭

- 制题不工：**候选筛查**；题目应简洁贴切，不明时可用首句为题。
- 远离题意：**硬伤／高优先修改**；改题或改词。
- 主观臆断、与史不符：**硬伤**；常识、生活观察、历史人物、事件、地理、制度不确定时先查证或避开。
- 盗版之作：**硬伤**；明显搬用前人成句或高度近似须改，定稿以查重辅助核验。
- 自我抄袭：**参考背景**；避免反复用自己的旧句旧法，依赖人工记忆与档案，不自动硬判。
- 忌蹈袭前人之**偷语、偷意、偷势**：逐句检查是否照搬或微改前人成句、重蹈名篇意境、或整体句式／节奏／转折／体势近于某篇名作。即内容不同，整体偷势亦须重构。遵“两忌三避”：忌俗、忌熟；避古人、避今人、避自己。

## 日常检查与报告

- 自动／半自动：无韵、重韵、出韵、平仄互押、失粘失对（词谱适用时）、平仄紊乱、孤平、三平调、同字重字、句句押韵、查重近似。
- 候选筛查：凑韵、合掌／语意重复、句法雷同、敷衍凑句、时空错乱、自相矛盾、写景泛泛、题意偏离、常识或史实错误。
- 人工点评：对偶、僻字叠字、出语突兀、章法、比喻夸张、用典、立意境界、体裁是否合宜。

候选稿仅列高价值项：

```text
词病自检：无明显硬伤 / 有可改处 / 有可商榷处。
硬伤：列必须改的 1–3 项。
可商榷：列保留理由或替代方案。
建议：优先最小改动，不为避小病伤大意。
```
