# 三稿风格图谱

参考钟嵘《诗品》的自然、滋味与风骨取向，以及司空图《二十四诗品》的品目。只取审美维度，不仿名家。

每个风格由四轴描述：**语势、意象、措辞、推进**。三稿至少两轴不同，并至少保留一稿“自然”。题材不合时不要硬选某一品目。

- **自然**：语势舒展；意象日常而准确；措辞朴素；推进顺势生发。
- **含蓄**：语势收敛；意象留白；措辞少断语；推进回旋，结尾余味长。
- **沉著**：语势稳重；意象有分量；措辞凝练；推进层层下沉后转出。
- **雄浑**：语势开阔；意象宏阔；措辞劲健；推进直进而有回荡。
- **冲淡**：语势平和；意象疏淡；措辞清浅；推进似断实连。
- **清奇**：语势峭拔；意象新警；措辞冷洁；推进有意外转折。
- **典雅**：语势从容；意象端整；措辞雅驯；推进严整，不堆典。
- **洗炼**：语势简捷；意象少而准；措辞高度节制；推进删繁就简。
- **劲健**：语势有骨；意象动态；措辞利落；推进多用动作推动。
- **绮丽**：语势流美；意象明艳；措辞精致；推进层层铺染但不过饰。
- **纤秾**：语势细密；意象近景；措辞柔润；推进从细节渐入情深。
- **高古**：语势简远；意象苍茫；措辞古朴；推进少机巧，多留天地之意。

## 选择规则

1. 先判断题材、素材尺度和主旨落点。
2. 排除与题材冲突的风格，不为凑三稿强配雄浑或绮丽。
3. 选择三种在至少两轴上不同的风格。
4. 一稿必须自然克制；其余两稿可扩大语势、意象或推进差异。
5. 对用户只说明风格和关键差别，不展示内部打分。
